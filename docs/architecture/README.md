# Архитектура Notification Subscription Platform

В этой папке собраны детали по основным частям системы. Документация описывает текущее состояние реализации в коде и помогает быстро понять, где находится бизнес-логика, как идут сообщения и какие инфраструктурные зависимости задействованы.

## Содержание
- [overview.md](overview.md) - слои приложения и основные компоненты
- [event-flow.md](event-flow.md) - путь события от API до отправки уведомления
- [data-model.md](data-model.md) - ключевые сущности, таблицы и статусы
- [security.md](security.md) - JWT, роли и ограничения доступа
- [operations.md](operations.md) - запуск, очереди, метрики и observability
